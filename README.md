# Tô no Corre

O **Tô no Corre** é uma ferramenta desenvolvida para facilitar a busca e
a organização de oportunidades de emprego.

O projeto surgiu de uma necessidade prática durante minha própria busca
por recolocação: reduzir o tempo gasto procurando vagas em diferentes
fontes e identificar com mais facilidade quais oportunidades são
compatíveis com o perfil do candidato.

## Funcionalidades

-   Busca de vagas em diferentes fontes públicas
-   Análise de compatibilidade entre currículo e vagas
-   Filtros por modalidade e tipo de oportunidade
-   Organização das vagas encontradas
-   Fila de candidaturas
-   Acompanhamento das candidaturas realizadas
-   Identificação de requisitos e informações relevantes das vagas
-   Configuração de preferências de busca

## Como funciona

O usuário fornece seu currículo localmente e configura suas
preferências.

A ferramenta utiliza essas informações para auxiliar na busca, análise e
organização das oportunidades encontradas.

O **Tô no Corre não realiza candidaturas automaticamente**.

A fila de candidaturas funciona apenas como uma ferramenta de
organização: as vagas são abertas individualmente para que o próprio
usuário realize a candidatura e registre posteriormente se já se
candidatou.

## Privacidade

Os dados utilizados pelo aplicativo são processados localmente.

Currículos, perfis locais, bancos de dados, logs e outros arquivos
pessoais ou gerados durante a utilização do programa não fazem parte do
código-fonte publicado neste repositório.

## Objetivo do projeto

Além de solucionar um problema que encontrei durante minha própria busca
por emprego, o projeto também faz parte do meu desenvolvimento prático
em programação.

A ferramenta vem sendo aprimorada a partir de testes reais, correção de
problemas e implementação de novas funcionalidades.

## Tecnologias

-   Python
-   Interface gráfica desktop
-   Integração com fontes públicas de vagas
-   Processamento e análise de informações de vagas
-   Persistência local de configurações e dados

## Status

🚧 **Projeto em desenvolvimento**

O Tô no Corre ainda está sendo testado e aprimorado. Funcionalidades,
interface e fontes de busca podem sofrer alterações.

## Aviso

O Tô no Corre é uma ferramenta independente para auxílio na busca e
organização de oportunidades.

O projeto não possui vínculo, parceria ou afiliação com LinkedIn,
Indeed, Gupy, Google ou outras plataformas eventualmente consultadas.

O usuário é responsável por verificar as informações das vagas
diretamente nas respectivas plataformas antes de realizar uma
candidatura.
