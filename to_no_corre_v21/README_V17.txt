V17 — NAVEGADOR FLEXÍVEL

Configurações > Navegador para candidaturas:
- Automático (recomendado)
- Google Chrome
- Microsoft Edge
- Brave
- Chromium interno
- Firefox (Playwright)

No modo Automático o app procura Chrome, depois Edge, depois Brave e usa Chromium como fallback.
Cada opção usa uma pasta de perfil de automação separada, sem reutilizar o perfil pessoal normal do navegador.

Execute preparar_navegador.bat na primeira instalação para instalar os navegadores do Playwright.
